# 前端补充功能验收（2026-09-20）

本轮承接剧本验收，重点检查此前未覆盖的页面与跨页面流程。结论仅覆盖下面的场景，不代表历史前端已不存在其他问题。

## 测试方式

- 在应用内浏览器操作真实页面，经过本地 API 和数据库保存、读取结果。
- `localhost:3000` 使用独立浏览器存储和本地演示模型；`127.0.0.1:3000` 的真实模型配置未修改。
- 新建带“验收”标识的测试书籍。研究样本甲、乙均由内置示例改成两章，未用真实剧本制造演示诊断结论。
- 演示模型只验证交互、请求、状态和结果展示，不能证明诊断质量、引导质量或真实模型稳定性。
- 窄屏检查使用 390 × 844 视口，结束后恢复浏览器默认尺寸。

## 已复现并修复

| 问题 | 修复与复测证据 |
| --- | --- |
| 复诊成功但章节仍显示“尚未诊断” | API 返回本轮完整诊断，前端在稿件未切换时安装报告；保存新版本后复诊，页面显示 3 条演示意见、5.4 分，待复诊归零。 |
| 新稿待复诊却显示“复诊已生成”，继承上一轮问题选择 | 待复诊优先于历史完成记录；更换报告清空选择，无待复诊版本时禁用复诊按钮。 |
| 修改指令混入未选中的问题 | 根据已加入计划的问题、约束、引文生成指令；实测只选 1 条时指令不含另 2 条。 |
| 深度质检错误依赖快速诊断结果，正常参考文本也无法开始 | 改为参考正文至少 80 字即可生成；未提供标题和市场标签时使用明确的“参考样本/未指定”。 |
| 深度质检失败信息不可见、查看发现按钮无动作 | 展示请求状态，连接发现锚点；实际观察到校验错误，修复后完成标准生成和评分。 |
| 评分前缺少正文字数限制，证据只显示前几项 | 按接口限制检查 80–30000 字，显示全部证据；演示结果 18 项均可查看。 |
| 只有发动机卡的书籍无法导出，JSON 遗漏卡片 | 计入书籍和导出页资产，JSON 包含卡片；仅 1 张卡、0 条修改记录时两种导出均触发成功反馈，单元测试校验导出字段。 |
| 图谱、资料和书籍页计数错误或硬编码 | 章节估计来自分析结果，已诊断章节按记录去重；情节模式、节奏使用真实结果字段，没有结果时明确提示。 |
| 整书已完成却显示 2/4 章节 | 章节数优先使用预处理章节和完成的章节索引，不用包含多个处理阶段的片段数；复测为 2/2。 |
| 研究对比、问答和资料导出反馈不可见 | 显示请求状态；处理期间限制重复操作。 |
| 切换对比样本后仍显示旧比较和旧答案 | 选择、问题或对比方向变化时清除相应结果；实测切换样本后旧内容消失。 |
| 同一本书多条引用触发 React 重复 key 报错 | 引用行使用包含条目序号的标识；再次问答未出现新的同类错误。 |
| 设置和快速诊断声称数据不会发送至后端 | 文案与实际保存和调用行为一致。 |
| 手机宽度下导出页横向溢出 | 约束网格最小宽度，复测页面宽度与内容宽度一致。 |
| 手机宽度下章节正文、右侧按钮被裁切 | 约束工作区列宽，窄屏标题栏与操作栏适配；截图确认正文完整，目录和意见抽屉可操作。 |
